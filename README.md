# VillageSlop

VillageSlop is the working title for a competitive 1v1 god game in which two
players guide autonomous villages, grow divine influence, and weaponize a
shared ecosystem. It combines indirect village management with readable RTS
competition and direct god-hand interactions.

The project will use a custom C++ engine. Low-level platform and transport
libraries are allowed, but gameplay, simulation, rendering, navigation, AI,
tools, and user interface remain project-owned code.

## Current status

Pre-production. The first deliverable is a deterministic, networked MVP rather
than a content-complete game.
